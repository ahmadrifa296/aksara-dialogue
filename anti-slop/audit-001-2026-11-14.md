## Numbered Findings List

### 1. [HIGH] R-02 — Forbidden Em Dash (`—`) in Metadata and Content
- **Files Affected:**
  - `app/layout.tsx:19`
  - `lib/queries/content.ts:318`
  - `lib/queries/homepage.ts:326`
  - `data/local-db.json:244`
- **Violation:** Em dash character (`—`) is used in the site title and sample text articles (`Aksara Dialogue — Suara Publik...`, `Jakarta — Aksara Dialogue...`).
- **One-line Reason:** Em dash is an absolute AI copy tell forbidden under R-02; replace with colon (`:`), hyphen (`-`), or natural phrasing.
- **Proposed Fix:** Change `Aksara Dialogue — Suara Publik, Ruang Dialog` to `Aksara Dialogue: Suara Publik, Ruang Dialog`, and update content intros to `Jakarta - Aksara Dialogue...` or comma-separated location leads.

---

### 2. [HIGH] R-39 — Missing Global Interactive Cursor Styles & Reduced Motion Handling
- **Files Affected:**
  - `app/globals.css:108`
- **Violation:** Missing base `cursor: pointer` on interactive elements (`a[href], button, summary, select, label[for]`), missing `cursor: not-allowed` on disabled controls, and missing `@media (prefers-reduced-motion: reduce)` block.
- **One-line Reason:** Every control must explicitly show affordance (`cursor: pointer`), and non-essential motion must pause for accessibility.
- **Proposed Fix:** Add standard base interactive rules (`button, a[href], summary, select, label[for] { cursor: pointer; }`, `button:disabled, input:disabled { cursor: not-allowed; }`) and a `@media (prefers-reduced-motion: reduce)` rule that disables animations and transitions.

---

### 3. [MEDIUM] R-04 & R-09 — Unjustified `Sparkles` Glyph in Badges and Section Headers
- **Files Affected:**
  - `components/public/hero-section.tsx:36`
  - `components/public/cta-section.tsx:45`
  - `app/(public)/fokus-gerakan/[slug]/page.tsx:75`
  - `app/(public)/tentang-kami/nilai-nilai/page.tsx:25`
  - `app/(public)/tentang-kami/profil/page.tsx:17`
- **Violation:** `Sparkles` icon is attached to category tags and section headers without specific contextual relevance.
- **One-line Reason:** `Sparkles` is an AI-generated signature icon that dilutes serious NGO branding; remove it or replace with clear semantic typography.
- **Proposed Fix:** Remove the decorative `Sparkles` icon from hero/CTA badges, keeping the bold typography clean and impactful.

### 4. [MEDIUM] R-08 — Obligatory Arrow Glyphs (`ArrowRight`) on CTA Buttons
- **Files Affected:**
  - `components/public/hero-section.tsx:59`
  - `components/public/navbar.tsx:146`
  - `components/public/cta-section.tsx:69`
  - `components/public/about-section.tsx:57`
  - `components/public/focus-section.tsx:47`
  - `components/public/news-section.tsx:48, 111, 126`
  - `components/public/programs-section.tsx:35, 93, 107`
  - `components/public/articles-section.tsx:33`
  - `components/public/gallery-section.tsx:34`
- **Violation:** Nearly every call-to-action button across hero, navbar, and cards appends `ArrowRight` by default.
- **One-line Reason:** Attaching arrows to every button is a repetitive AI visual cliché that adds noise without visual purpose.
- **Proposed Fix:** Keep `ArrowRight` only on directional reading links ("Baca Selengkapnya"), and remove it from standard action buttons ("Hubungi Kami", "Donasi / Dukung Kami", "Lihat Semua Program").

### 5. [LOW] antislop-code & R-31 — Restating-the-Obvious JSX Comments and Decorative CSS Banners
- **Files Affected:**
  - `components/public/hero-section.tsx:27, 34, 40, 45, 51`
  - `app/globals.css:3, 104, 125, 136, 187, 205, 232`
- **Violation:** JSX comments narrate each element (`{/* Tag / Category Badge */}`, `{/* Main Tall Condensed Headline */}`, `{/* CTA Action Buttons */}`); CSS contains decorative ASCII bars (`/* ======================================== */`).
- **One-line Reason:** Comments that restate what the code already shows add reading burden, and banner comments read as AI generator noise.
- **Proposed Fix:** Strip redundant JSX narration comments and simplify CSS headers to single clean comment lines.
