🌐 Latar Belakang & Visi

MENGAPA MEMBANGUN
AKSARA DIALOGUE?

Ruang dialog masyarakat sipil sering kali terfragmentasi. Dibutuhkan sebuah platform digital yang mandiri, transparan, dan mudah dikelola untuk diseminasi riset kebijakan serta agenda warga.

⚠

Tantangan Lapangan

Pengelolaan data advokasi sering terpencar, publikasi sulit diperbarui secara real-time, dan tampilan web lama kaku saat dibuka lewat ponsel.

✔

Solusi yang Dihadirkan

Ekosistem web terpadu dengan Content Management System (CMS) mandiri, database cloud Supabase, dan desain responsif mobile yang cepat.

🎯

Fokus Isu Warga

Mewadahi 4 pilar advokasi utama: Keadilan Sosial, Demokrasi Kebijakan, Kelestarian Ekologis, serta Keadilan Gender & Inklusi.

👥

Kolaborasi Nyata

Menghubungkan suara akademisi, pegiat HAM, aktivis mahasiswa, dan warga akar rumput dalam satu ruang wacana yang terbuka.

MODERN STACK UNTUK
PERFORMA & KEANDALAN

Dipilih teknologi web generasi terbaru untuk memastikan website dapat diakses cepat dari jaringan seluler mana pun tanpa mengorbankan keamanan data.

▲ Next.js v16 Turbopack
⚡ Supabase PostgreSQL
🎨 Tailwind CSS Responsive
TS TypeScript Strict Mode
▲ Vercel CI/CD Deploy
🚀

Next.js 16 App Router

Server Actions & Server Components memberikan loading instan, SEO terindeks optimal, dan rendering cepat tanpa jeda putih.

🔐

Supabase Cloud Database

PostgreSQL cloud dengan Row Level Security (RLS) serta storage media terintegrasi untuk penyimpanan berita, album, dan dokumen.

📱

Mobile-First Reflow

Pengalaman mobile adaptif dengan grid 2 kolom ala Shopee dan fixed bottom navigation bar untuk navigasi jempol yang nyaman.

⚙

Dual-Database Sync

Dukungan fallback offline lokal (`local-db.json`) tersinkronisasi otomatis dengan Supabase saat proses redeploy.
